# Code of Conduct

## Nosso compromisso

Este projeto mantém um ambiente aberto e respeitoso. Contribuidores de qualquer background são bem-vindos, independentemente de experiência, identidade ou localização.

## Comportamento esperado

- Linguagem inclusiva e respeitosa
- Feedback técnico objetivo e construtivo
- Aceitar críticas e sugestões com abertura
- Foco no que é melhor para o projeto e para a comunidade

## Comportamento inaceitável

- Linguagem ou imagens ofensivas
- Ataques pessoais ou políticos
- Assédio público ou privado
- Compartilhar informações privadas de terceiros sem consentimento

## Aplicação

Comportamento inaceitável pode ser reportado ao mantenedor via e-mail listado no perfil do GitHub. Todos os reports serão tratados com confidencialidade.

Este documento é uma adaptação simplificada do [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
